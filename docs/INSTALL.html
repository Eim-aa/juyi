句译 · 选中英文，连按两次 Option（⌥⌥），在选区旁查看中文。

开发者预览：这份说明和本地 DMG 不表示签名、公证或首次安装验收已经通过。公众发行状态以 GitHub Releases 为准。若 macOS 阻止打开，请等待合格发行包；不要关闭 Gatekeeper 或移除隔离属性。

1. 安装到“应用程序”

  1. 需要 macOS 15 或更新系统。安装包包含 Apple Silicon 与 Intel 架构；这不代表两类硬件均已实测。
  2. 更新前正常退出旧版句译，并保留旧安装包以便回退。把 DMG 内的句译.app拖到Applications，然后从“应用程序”打开句译，不要直接在 DMG 中启用。
  3. 当前预览仍需 Hammerspoon。从其官网下载安装到“应用程序”，打开一次，再回句译点击继续。句译会准备兼容组件；不要同时运行旧的独立翻译快捷键。

2. 按句译的提示完成准备

  1. 点击启用原生双 Option。按系统提示到“系统设置 → 隐私与安全性 → 辅助功能”，允许句译，然后回到 App。权限必须由你本人确认。
  2. 保留本地翻译 · Apple。首次使用可能需要联网下载中英语言资源，按系统提示确认；准备完成后正文可在本机离线翻译。
  3. 在练习页打开文本编辑示例，选中英文，连续按两次 Option。不是同时按住两个 Option，也不是双击鼠标。译文出现在选区附近。

3. 日常使用与隐私

  • 关闭主窗口后仍在菜单栏运行。“暂停所有翻译”停止触发；退出再打开后点击“恢复翻译”。
  • 当前仅支持英语 → 简体中文。文字型 PDF 和其他 App 能否读取取决于其选区接口；扫描件、图片、安全输入框与受保护内容不支持，没有 OCR。
  • 预览与 WPS 的 PDF 行尾断词会进行保守整理；罕见词、专有名词和跨栏文本仍可能有误。
  • WPS PDF 兼容路径可能临时使用复制并尽力恢复剪贴板。剪贴板管理器可能保留原文，敏感内容请避免该路径。
  • 本地翻译不要求 Python、Homebrew 或开发工具。可选云端目前仅支持火山，需要独立的后台安装和火山密钥，属于高级源码安装；只安装这个 App 不等于已配置云端。选择云端会把文字发送给火山，不会在本地失败时自动切换。

遇到问题

先查看句译首页提示及“诊断与帮助”。若读不到选区，重新划选英文并保持原 App 在前台。不要反复重装或修改系统权限数据库。

反馈到 GitHub Issues：附句译版本、macOS 版本、阅读器名称和不含隐私的复现步骤；不要提交密钥、完整私人文档或未裁剪桌面录像。
