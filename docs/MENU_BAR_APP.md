# 句译原生 macOS App

句译是 **macOS 15+ 公开测试版**，不是稳定版。App 独立完成全部链路：双 Option 监听、辅助功能取词、翻译（Apple 本地或火山云端）、译文浮窗与朗读。不需要 Hammerspoon、Python、后台服务或 Homebrew。用户目标是在支持的 App 选中英文，连按两次 Option（⌥⌥）查看简体中文。

## 安装

从 [GitHub Releases](https://github.com/Eim-aa/juyi/releases) 下载标明已签名、公证的最新 DMG，无需登录 GitHub。将句译拖到“应用程序”（`/Applications/句译.app`）后打开，按照 [安装与第一次翻译](../README.md#三步开始) 完成授权和语言资源准备。请核对对应版本的发布说明：已发布的 build 16 的火山云端仍依赖旧的后台组件，源码 build 17 起云端由 App 直连。

开发者也可以从源码构建并安装到系统“应用程序”：

```bash
scripts/install_macos_app.sh
```

脚本先构建并校验版本与 ad-hoc 签名，再更新 `/Applications/句译.app`；此签名检查不能替代 Developer ID 与公证。需要时 macOS 会显示管理员授权窗口。新 App 验证成功后才把旧的个人“应用程序”副本移到废纸篓。用户的引擎选择和钥匙串中的火山密钥不会被删除。详见 [从源码构建](BUILD.md)。

## 早期组件

build 17 之前的源码安装会留下 Hammerspoon 快捷键模块（`~/.hammerspoon` 中的符号链接与 `init.lua` 托管块）、本地后台服务的 LaunchAgent 和 `~/.config/argos-translator` 中的文件。句译在启动时、每次启用前以及定期刷新时检测这些组件；检测到时**不启用**双 Option（fail-closed），避免同一次按键被两条路径翻译。首页、第一次使用和“诊断与帮助”会显示同一状态：

- **检测到早期组件** → 按钮“移除早期组件”。一次点击会：停止并删除旧后台的 LaunchAgent；删除句译创建的模块符号链接与 `init.lua` 中的托管块（其他 Hammerspoon 配置不变）；清空并删除 `~/.config/argos-translator`；若 Hammerspoon 正在运行则重新启动它，使其不再载入旧模块。旧版明文 `volc.env` 中的火山密钥会先迁移到钥匙串；无法确认钥匙串状态时不删除任何文件。
- **早期组件需要手动处理** → 列出不是句译创建的同名文件或链接，句译不会改动；手动移走后点“重新检查”。
- **请重新启动 Hammerspoon** → 模块已移除，但仍在运行的 Hammerspoon 可能保留旧配置；按钮“重新启动 Hammerspoon”，或手动退出再打开。

移除完成后，之前已启用的双 Option 会自动恢复；从未启用时按“启用双 Option”继续。全新安装不会出现这些状态。

## 第一次使用

安装后直接从“应用程序”打开“句译”，不需要终端。首次启动会出现一个可跳过、可继续的两步教学（欢迎页之后依次为“第 1 步 · 准备”“第 2 步 · 练习”，最后是“完成”）：

1. **准备（启用原生双 Option）**：按界面提示在“系统设置 → 隐私与安全性 → 辅助功能”为 **句译** 开启权限，回到 App 后会复检。此权限必须由用户本人授予。本地翻译还需准备 Apple 中英语言资源；火山云端需要先保存密钥。检测到早期组件时，这一步会先要求移除它们。
2. **练习（实际试用）**：点击“打开文本编辑”，新建文稿，输入并选中 `Good tools should feel effortless.`，再快速连按两次 Option。看到原生译文浮窗后回到句译点“我看到了译文”。句译自身窗口不会被当作取词目标。需要语言包时在句译点击“准备 Apple 语言包”，按 macOS 提示确认。

完成页只保留一句用法提示和“后台运行与停止…”链接，关闭窗口、暂停与退出的区别统一在“支持范围与隐私”中说明。每一步都可以点“稍后再说”。这不会被误记为完成；主界面和菜单栏会保留“继续设置”入口。完成后可以从主界面的“重新练习双 Option”再练一次，也可以在“诊断与帮助”中完整重新运行设置。重新运行不会清除引擎选择或云端密钥。

如果窗口被关闭，句译仍会留在 Dock 和菜单栏；点击 Dock 图标或菜单栏中的句译图标即可重新打开唯一的控制窗口。首次教学只有在用户明确确认看到了译文后才算完成。

## 支持范围与隐私

先在文本编辑中验证最短路径，再尝试自己的常用 App。其他 App 和带文本层 PDF 的选区能否读取，取决于其辅助功能接口；扫描图片 PDF、安全输入框与受保护内容不支持。代码中具备某种读取路径不等于已验证所有应用版本，具体候选包验收见 [产品审查记录](dev/PRODUCT_REVIEW_2026-09-22.md)。

WPS PDF 不提供可用选区接口时，兼容取词可能临时执行系统复制，并尽力恢复原剪贴板。剪贴板管理器可能保留原文或干扰取词；敏感内容请避免使用这条路径。欢迎页与练习页各保留一句简短提醒，详细说明只放在“支持范围与隐私”。

## 翻译方式

两种方式共用同一条原生链路：同样的双 Option、取词、浮窗与朗读，只有译文来源与浮窗元数据（如“火山云端 · N 毫秒”）不同。任何一方失败都不会自动改用另一方。

- **Apple 离线**：默认选项；文本只在本机处理，需要 macOS 15+ 和系统中英语言包。
- **火山云端**：可选联网模式，目前仅支持火山翻译。在“翻译方式”中选择“使用云端翻译…”，填入火山的 Access Key ID 与 Secret Access Key 并点“保存并验证”。句译用一句固定英文实测通过后才写入 macOS 钥匙串（服务名 `io.github.Eim-aa.juyi.volc`），验证失败时原有配置不变。启用后，你主动选中并触发翻译的英文会直接从句译发送至火山翻译；不需要任何后台组件。

密钥只保存在钥匙串，不写入源码、仓库、日志、UserDefaults 或任何文件；句译只在翻译或验证时发出请求，不做预热。“移除已有云端配置…”会从钥匙串删除密钥并切换回 Apple 离线。是否更适合自己的内容，建议用固定语料对比两种方式。

## 菜单栏

句译菜单按六组排列：当前状态、打开句译、翻译方式、暂停/恢复（未就绪时为下一步设置动作，例如“移除早期组件”）、诊断与帮助（含支持范围与隐私、继续设置或重新练习）、退出句译。

关闭窗口继续翻译；“暂停翻译”停止翻译，保留控制界面；“退出句译”会记住暂停状态并停止翻译，重开后需点击“恢复翻译”，教学中重开也提供恢复入口。

“诊断与帮助”分为“状态与修复”（当前状态、早期组件状态、重新检查、重新启用双 Option、辅助功能设置、准备 Apple 语言包或检查火山云端设置，以及需要时的“移除早期组件”）和“设置”（登录时自动打开、测试当前翻译方式、重新运行设置），底部链接打开“支持范围与隐私”。“测试翻译引擎”对当前引擎翻译一句固定样例，只证明引擎能翻译，不能代替新手教学里的真实选区与双 Option 试用。

译文浮窗支持点击复制完整译文、按 Escape 关闭和点击外部关闭。长译文在屏幕内安全截断展示，复制时仍会得到完整内容；连续触发时，旧请求的定时器或迟到响应不会覆盖较新的译文。

### 听原文和译文（build 16 起）

翻译成功后，浮窗底部提供「朗读原文」和「朗读译文」。点击即可听英文原文或完整中文译文；再次点击当前按钮停止，点击另一个按钮切换。不会自动播放，也不新增快捷键。关闭浮窗、触发新选区、暂停或退出句译都会停止朗读。

朗读使用 Mac 已安装的 Apple 系统语音，不需要 API 密钥或麦克风权限，不调用第三方语音服务或个人声音。缺少英语或普通话语音时会提示到系统设置的辅助功能中下载；不会自动下载或切换云端。仅能朗读本次实际取得的文本，取词被截断时无法补回未取得的部分。

Dock 与菜单栏会同时保留句译入口。关闭窗口只关闭控制窗口，不会退出句译或移除双 Option 快捷键；从 Dock、Finder、Launchpad 或菜单栏再次打开时，会前置同一个窗口。

## 登录时自动打开

首次打开时，句译会尝试把自己注册为登录项，让 Dock 与菜单栏入口在下次登录后自动出现。即使注册失败也不会阻止当前翻译。

可在“诊断与帮助 → 设置”中开关“登录时自动打开句译”。界面会区分已开启、未开启、需要系统确认和 App 路径不可用；需要用户确认时，可直接打开“系统设置 → 通用 → 登录项”。

登录启动不会自动弹出控制窗口，但 Dock 与菜单栏入口都会出现。源码的 ad-hoc 本地构建在系统登录项 API 不可用时，会自动使用当前用户的兼容登录设置（`io.github.Eim-aa.Juyi.login-item` LaunchAgent）；正式 Developer ID 构建继续使用 macOS 的 ServiceManagement。两种路径共用同一个界面开关。

## 卸载

在“诊断与帮助”中关闭“登录时自动打开句译”，退出句译，把它移到废纸篓，再到“系统设置 → 隐私与安全性 → 辅助功能”中移除句译。也可以运行 `scripts/uninstall.sh`：它会退出句译、移除登录项、询问是否删除钥匙串中的火山密钥、清理早期版本留下的组件（旧后台 LaunchAgent、句译创建的 Hammerspoon 模块链接与托管块、`~/.config/argos-translator`），最后把句译移到废纸篓。

## 开发与发布

```bash
xcodebuild -project Juyi.xcodeproj -scheme Juyi \
  -configuration Debug -derivedDataPath /tmp/JuyiDebug build
open /tmp/JuyiDebug/Build/Products/Debug/Juyi.app
```

工程只有一个 App target，产物为 Universal 2（Apple Silicon + Intel），最低支持 macOS 15.0。`scripts/build_macos_app.sh` 读取与 Xcode 相同的版本和 deployment target，供安装脚本使用。本地源码构建使用 ad-hoc 签名；公开下载版本在发布前仍必须配置 Developer ID 签名与 Apple 公证。完整构建契约见 [RELEASE_BASELINE.md](RELEASE_BASELINE.md)。

每次公开新版都必须重新签名、公证、验证下载包；源码构建不自动获得发行信任。干净账户和不同硬件上的真实端到端验收仍须单独记录。当前刻意不扩展新翻译供应商、多语言、OCR 或翻译历史。
