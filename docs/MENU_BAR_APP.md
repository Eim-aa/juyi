# 句译原生 macOS App

句译 App 是现有 Python 翻译服务与 Hammerspoon 快捷键之上的原生产品界面。普通使用时不需要了解这些后台组件；选中英文，快速连按两次 Option（⌥⌥）即可看到中文。

## 安装

当前开发阶段尚未提供正式下载包、DMG 或图形安装器。现有正式路径是把源码放到运行目录后执行 `scripts/install.sh`；它会准备翻译服务，通过 Homebrew 安装并打开 Hammerspoon，并安装 `/Applications/句译.app`：

```bash
git clone https://github.com/Eim-aa/juyi.git ~/.local/share/argos-translator
~/.local/share/argos-translator/scripts/install.sh
```

只重新构建和安装原生 App：

```bash
~/.local/share/argos-translator/scripts/install_macos_app.sh
```

安装脚本会先构建并校验版本与签名，再安全更新系统“应用程序”中的 App；需要时 macOS 会显示管理员授权窗口。只有新 App 验证成功后，脚本才会把旧的个人“应用程序”副本移到废纸篓。用户的引擎选择和 macOS 钥匙串中的火山密钥不会被删除。脚本不会覆盖用户自定义的同名 Hammerspoon 模块；检测到冲突时会停止并给出处理提示。

## 第一次使用

`scripts/install.sh` 成功完成后，日常使用不需要终端；直接从“应用程序”打开“句译”。首次启动会出现一个可跳过、可继续的三步教学：

1. **准备翻译**：自动检查后台组件，并优先验证 Apple 离线翻译。已有且验证过的火山云端设置不会被覆盖。
2. **允许快捷键**：按界面提示打开“系统设置 → 隐私与安全性 → 辅助功能”，为 **Hammerspoon** 开启权限。此权限必须由用户本人授予；回到句译后会立即复检。
3. **实际试用**：用鼠标或键盘选中界面中的示例英文，快速连按两次 Option。看到浮动译文后点“我看到了译文”。

每一步都可以点“稍后再说”。这不会被误记为完成；主界面和菜单栏会保留“继续设置”入口。完成后可以从主界面的“重新学习”直接再练一次快捷键，也可以在“诊断与帮助”中完整重新运行设置。重新运行不会清除引擎选择或云端密钥。

如果窗口被关闭，句译仍会留在 Dock 和菜单栏；点击 Dock 图标或菜单栏中的句译图标即可重新打开唯一的控制窗口，也可以以后从 Launchpad 或系统“应用程序”再次打开。首次教学只有在用户明确确认看到了译文后才算完成。

界面会读取 Hammerspoon 写出的真实授权与热键监听状态，不会仅凭后台进程在线就显示“已就绪”。

## 翻译方式

- **Apple 离线**：默认选项；文本只在本机处理，需要 macOS 15+ 和系统中英语言包。
- **火山云端**：可选联网模式；选中的英文会发送至火山翻译，是否更适合应用自己的固定语料对比。未配置时点击卡片即可进入设置。

火山密钥有常驻字段标签、显隐控制和真实翻译验证。候选密钥先保存到独立的 pending 钥匙串项，验证成功后才替换正式凭据；pending 标记会保留到服务重启和正式凭据实测均成功，意外中断时下次启动会前向完成或安全清理。验证失败时不会覆盖旧配置。移除云端配置也使用持久事务标记；标记存在或无法验证时，Hammerspoon 与本地服务都会逐请求阻止云端翻译。密钥不写入源码、仓库、HTTP 请求正文或运行日志。旧版 `volc.env` 中的 AK/SK 会安全迁移到钥匙串。Apple 离线不可用时不会静默回退云端。

原生 App 与 Hammerspoon 调用本地服务时会携带安装阶段生成的随机令牌。令牌只对当前用户可读，用于阻止浏览器页面或无权读取令牌的本机客户端调用翻译与密钥验证接口。

## 菜单栏

原生句译是唯一的句译菜单入口，提供当前状态、打开窗口、切换引擎、暂停/恢复和诊断。Hammerspoon 仍处理热键和译文浮窗，但不再创建第二个句译菜单。

“退出句译”会关闭 Dock 与菜单栏中的原生控制界面，但后台翻译组件仍可继续运行；如需暂时关闭双 Option 热键，请使用“暂停句译”。

“测试当前翻译方式”位于“诊断与帮助”中，只验证翻译后端；它不能代替新手教学里的真实双 Option 试用。

译文浮窗支持点击复制完整译文、按 Escape 关闭和点击外部关闭。长译文在屏幕内安全截断展示，复制时仍会得到完整内容；连续触发时，旧请求的定时器或迟到响应不会覆盖较新的译文。

Dock 与菜单栏会同时保留句译入口。关闭窗口只关闭控制窗口，不会退出句译、停止后台翻译组件或移除双 Option 快捷键；从 Dock、Finder、Launchpad 或菜单栏再次打开时，会前置同一个窗口。

## 登录时自动打开

首次打开时，句译会尝试把自己注册为登录项，让 Dock 与菜单栏入口在下次登录后自动出现。这个设置独立于翻译服务，即使注册失败也不会阻止当前翻译。

可在“诊断与帮助”中开关“登录时自动打开句译”。界面会区分已开启、未开启、需要系统确认和 App 路径不可用；需要用户确认时，可直接打开“系统设置 → 通用 → 登录项”。

登录启动不会自动弹出控制窗口，但 Dock 与菜单栏入口都会出现。源码的 ad-hoc 本地构建在系统登录项 API 不可用时，会自动使用当前用户的兼容登录设置；正式 Developer ID 构建继续使用 macOS 的 ServiceManagement。两种路径共用同一个界面开关，用户不需要了解内部差异。

## 开发与发布

```bash
scripts/build_macos_app.sh
open build/Juyi.app
```

构建产物是带图标的 Universal 2 App（Apple Silicon + Intel），最低支持 macOS 13；Apple 离线翻译仍要求 macOS 15+。本地源码构建使用 ad-hoc 签名。公开下载版本在发布前仍必须配置 Developer ID 签名与 Apple 公证。

当前阶段的原生 App 是现有 Python 后端和 Hammerspoon 之上的产品界面。安装脚本成功完成以后，日常启动、状态查看、权限引导、引擎切换、密钥设置和错误恢复均在图形界面中完成。将后端运行时封装进签名、公证的 DMG/PKG 属于后续发行工程，本阶段不伪装为已经完成。

第一阶段刻意保留 Python 后端和 Hammerspoon 的双 Option/浮窗实现，不扩展新翻译供应商、多语言、OCR 或翻译历史。
