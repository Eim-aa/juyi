# 句译产品审查 · 2026-09-22

## 结论与证据边界

目标用户是普通 macOS 用户，目标路径是“下载/安装 → 为句译授权 → 在常用 App/PDF 选英文 → 双 Option → 查看本机中文译文”。当前可以继续作为开发者预览，**尚不建议标为普通用户正式发行版**。

首轮审查基线为 `codex/release-hardening` 的 `168886d`，依据仓库源码、产品说明及主代理转述的现有安装界面。旧版 `0.3.3` 曾出现首页“已就绪”与“正在启用”并存；该现象不是 `0.4.0` build `9` 的实测证据。本轮候选修改的静态复审不等于真实首次安装、语言下载或 PDF 兼容验收。本文不以测试数量、代码量或主观分数评价产品。

## 依赖与隐私校准

- Homebrew、Python 和 Xcode/Command Line Tools 是当前完整源码安装流程的要求；预编译原生 App 的 Apple 翻译直接使用系统框架，不需要 Python 服务。当前 Hammerspoon 兼容组件仍是首次启用前提。
- 原生 Apple 的权限授予对象是**句译**，不是 Hammerspoon。英文说明已纠正旧授权步骤和旧架构图。
- 关闭窗口继续运行；暂停和退出停止翻译；退出后重开需用户恢复。不能把“后台进程仍在”误写成“退出后仍应翻译”。
- Apple 正文在本机处理，语言资源由系统下载；主动选择云端会上传选区。WPS PDF 兼容路径可能临时使用剪贴板，管理器可能保留原文；离线翻译不等于剪贴板对其他软件不可见。
- 代码读取能力不是全部 App/PDF 兼容证据。不承诺扫描 PDF、受保护内容、所有可选文本 App 或固定翻译延迟。

## 本轮实际验证（本地预览）

- 在 macOS `26.5.1` 构建并安装 `0.4.0 (9)` 到 `/Applications/句译.app`。App 为 Universal 2，最低 deployment target 为 macOS 15.0；这不是 macOS 15 真机验收。
- 使用 Computer Use 操作真实候选：首页点击启用，界面经过“正在更新兼容组件”后变为一致的“句译已就绪 / 已启用”。当前模块已部署，Hammerspoon 状态为 `yielded`，`watcher_active=false`，旧请求与浮窗均不活跃。新版主页与次级云端入口已可见。
- 实测临时卸载 Python LaunchAgent 后端口关闭；此时 Computer Use 的 native pipe 断开，重置连接也未恢复。因此**没有把这次尝试记为无后台翻译成功**。原 LaunchAgent 已恢复。
- 暂停/退出/重开、语言包准备、真实全局双 Option 和 PDF 回归仍待候选版实测。当前 Computer Use 按键接口也不支持触发全局快捷键；引擎样例成功不能替代真实用户手势。
- 本地 Swift Release 构建、Python 回归、Lua 5.4 排队回调行为回归与格式检查通过。Lua 回归用旧源码运行时会因暂停后仍读 AX 而失败，证明它覆盖了实际修复；这些结果不替代以上用户路径验收。
- Developer ID 私钥签名请求未完成。用户明确选择暂不授权、先完成本地预览；当前安装候选使用 ad-hoc + Hardened Runtime，不是 Developer ID 公证发行包。

独立审查代理在看过 build 9 实际截图后的复审结论：主页未发现新的必修界面问题，可以继续本地开发者预览；不批准把当前状态称为端到端验收通过或正式公开发行。CUA 断连只是验收渠道受阻，不代表未测功能成功或失败。

## 仍待候选包实测的清单

以下作为完整验收清单；上节只关闭了版本确认及实际启用/主页状态部分，不宣称其余 build 9 路径已经通过。

1. 确认运行的是 `0.4.0 (9)`，不是旧 `0.3.3` 或另一构建副本；保存主页、首次设置、诊断与暂停截图。
2. 首次授权只引导用户给句译权限；拒绝后可继续，返回 App 会复检；缺 Hammerspoon 有可执行的下一步。
3. TextEdit 的固定英文选区完成真实双 Option 翻译；关闭控制窗口仍能使用。固定引擎自测不能替代此项。
4. 首页与菜单在交接、暂停、权限撤销、缺语言包、Python 服务不可用时状态一致。
5. 无语言包时完成准备；取消后可重试；准备或故障恢复期间旧链不接管，暂停/退出取消在途操作。
6. 教学第 1/2 步分别退出再开，可以先恢复再继续；完成教学后的暂停、退出与重开恢复也一致。暂停或退出期间不出现译文、不读取新选区、不修改剪贴板。
7. 逐项记录 Safari/Chromium、Preview 文本 PDF、WPS 文本 PDF 的 App/系统版本、成功或限制；扫描 PDF 和安全输入场景安全拒绝，WPS 剪贴板恢复及管理器干扰边界明确。
8. 已有云端配置仍保留可访问入口与上传提示；不因首页收敛而删除密钥或默认改为上传。无需为 Apple 验收上传用户正文。

## 正式发行门槛与暂缓范围

Developer ID、timestamp、公证、staple、Gatekeeper 验证、可信下载产物，以及干净账户的完整安装体验仍是正式发布门槛，详见 [RELEASE_BASELINE.md](RELEASE_BASELINE.md)。源码构建成功或现有用户机器能运行，不足以替代这些证据。

暂缓新供应商、多语言、OCR、翻译历史、额外 Labs/flags、owner 大规模重构和纯视觉精修。优先把现有 Apple-only 用户路径及失败恢复做到一致、可理解、可验证。
