# 句译 0.4.0 · build 15（取词反馈改进测试版）

## 用户可见变化

双 Option 被识别后，句译先显示“正在读取选中文字…”，取词成功后在同一浮窗中继续翻译。不再等 WPS 的全部取词校验结束才首次显示浮窗。读取期间可以关闭浮窗取消；较快的取词仍经过原有防闪烁延迟。

翻译等待计时从取词成功后开始，不会把较慢的 PDF 读取时间算进 Apple 翻译超时。浮窗不激活来源应用之外的窗口；如果屏幕边界导致浮窗覆盖原始 AX 命中点，则延后显示，避免遮挡取词。

本次没有缩短 WPS 的两次复制确认和安全等待，没有放宽剪贴板恢复、权限或 owner 互斥检查，没有新增 Lab、编译开关或抽象层。临时排查日志已移除，发布构建不包含这些诊断日志。
