# 句译 0.4.0 · build 15（取词反馈改进测试版）

## 用户可见变化

双 Option 被识别后，句译先显示“正在读取选中文字…”，取词成功后在同一浮窗中继续翻译。不再等 WPS 的全部取词校验结束才首次显示浮窗。读取期间可以关闭浮窗取消；较快的取词仍经过原有防闪烁延迟。

翻译等待计时从取词成功后开始，不会把较慢的 PDF 读取时间算进 Apple 翻译超时。浮窗不激活来源应用之外的窗口；如果屏幕边界导致浮窗覆盖原始 AX 命中点，则延后显示，避免遮挡取词。

本次没有缩短 WPS 的两次复制确认和安全等待，没有放宽剪贴板恢复、权限或 owner 互斥检查，没有新增 Lab、编译开关或抽象层。临时排查日志已移除，发布构建不包含这些诊断日志。

## 已有验证证据（2026-09-26）

- 本机 build 15 候选在 WPS PDF 上，用户确认能够翻译且弹窗反馈正常。两次诊断记录的真实手势识别至首次显示浮窗分别为 190 ms 和 181 ms；此前对应等待约 2.6 秒。这是首次反馈时间，不是完整译文耗时或普遍性能保证。
- 测速及用户确认来自清理日志前、安装在 `/Applications/句译.app` 的 build 15 本地候选；不能把它等同于后续发布 DMG 的逐字节验收。清理仅移除诊断日志，不改变取词逻辑。
- 既有模型回归覆盖读取期间取消、同代进入翻译、过期回调、失败与重复请求；独立代码复核未发现新的发布阻断问题。完整 Python 回归和静态检查通过。

## 发布边界

这是公开测试版候选，不是稳定版。签名、公证、CI 与匿名下载的最终结果记录在对应 GitHub Release 中；只有通过包级校验后才发布下载文件。

WPS 本次实测正常不等于间歇性“暂不支持”的根因已彻底修复。本次未改 WPS 取词规则。干净账户首次安装、系统权限撤回再授权、macOS 15 / Intel 真机，以及最终发布包上的 Preview、暂停时不触发和读取中关闭等真实交互，仍须分别记录，不能用自动测试代替。

安装方式仍为下载 DMG、拖入 Applications、打开句译并完成辅助功能授权和必要的 Apple 语言资源准备。全新 Apple 本地安装不要求 Hammerspoon、Python、Homebrew 或 API 密钥；已有开发组件保持原有 fail-closed 交接。保留 build 13 的下载作为回退选择。
