# 句译 0.4.0 build 10 · 设计优化本地预览

## 本轮实现

基于外部设计师提供的 HTML 方案，改进现有原生界面；不是把网页嵌进 App。

- 首页默认 520 × 520：状态标签、主操作、设置列表。首页和菜单栏共用已有实时状态的展示与主操作，区分未启用、设置中、就绪、暂停、需要处理。
- 兼容 watcher 可能仍在运行时，保留“暂停所有翻译”，不把原生未启用误当成所有路径已经停止。
- 增加独立的支持范围与隐私页；说明 PDF 的实际边界、WPS 剪贴板例外、Apple 不自动转云端。
- 首次设置显示兼容组件、句译权限、Apple 语言资源三项准备，移除“支持多数 App”的宽泛承诺。
- 练习按钮在文本编辑中打开本次生成的示例文稿，不修改剪贴板或现有文档。未就绪时，底部提供返回检查入口，不让用户面对无解释的禁用确认按钮。
- 关闭窗口、暂停、退出的说明统一；退出后重开仍需手动恢复。
- 浮窗成功态移除重复标题，将同一关闭按钮移至正文旁；正文 15 pt、较宽行距，按文本测量高度，保留长文滚动、复制、焦点和关闭逻辑。
- 复制反馈保留 2 秒；截断说明同时覆盖原文和返回结果的限制，不写死设计稿中的 2000 字。
- 界面继续使用系统语义颜色、原生材质及已有高对比度/减少透明度支持，未引入网络字体或网页运行时。
