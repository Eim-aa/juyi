# Spec 1：菜单栏控制中心与首次运行向导

状态：待评审 · 工作量：~4–6 人日（P0 约 3 + P1 约 2） · 依赖：建议先落 Spec 3 P0-1（错误展示）

## 问题陈述

对非技术用户，当前产品在三个环节静默流失：**装完不知道怎么触发**（无任何引导告知
"双击 ⌥"）、**坏了不知道为什么**（服务未启动/未授权时只有一句"未检测到选中文本"或
连接失败，修复手段是去终端跑 test.sh）、**配云端必须开终端**（手写 volc.env）。
菜单栏图标（hammerspoon/argos-translator.lua:357）已经存在但只承载切引擎一件事。
Hammerspoon 自带 `hs.dialog` / `hs.accessibilityState` / `hs.execute` 能力，
足以在**不改三件套架构**的前提下把这三个流失点全部堵上。

## 目标

1. 云端引擎配置全程零终端：从菜单栏对话框完成 AK/SK 录入到生效。
2. 服务/授权类故障的自助恢复：用户不离开菜单栏即可看到原因并一键修复，
   目标是"双击无反应"类问题不再需要打开终端。
3. 新安装用户被引导完成授权、语言包、首次翻译三步，装完 5 分钟内完成第一次成功翻译。
4. 译文可带走：浮窗支持一步复制。

## 非目标

- **不做独立设置窗口 / Web 设置页**：菜单 + 系统对话框覆盖本版全部配置面；
  Web 设置页记录为 P2 备选。
- **不改核心交互**：双击 ⌥ 触发、浮窗展示、点外部消失的行为不变；
  双击窗口时长等参数的图形化调节为 P2。
- **不代装 Hammerspoon**：向导运行在 Hammerspoon 内，无法解决"HS 未安装"
  （鸡生蛋），该环节属于 Spec 2 的安装链路。
- **不做翻译历史/生词本**（见总览非目标）。
- **不做原生 app**：本 spec 恰是"不重写前提下的体验上限"，实现中不得引入
  仅为未来重写服务的抽象。

## User Stories

按优先级排序：

- 作为**非技术用户**，服务没起来时我想在菜单栏看到红色状态和一个"修复"按钮，
  点一下就恢复，这样我不用知道 launchctl 是什么。
- 作为**非技术用户**，我想在菜单栏点"配置云端翻译"，在弹窗里粘贴两个 Key 就能
  切到云端，这样我不需要会创建隐藏目录里的配置文件。
- 作为**新安装用户**，首次加载时我想被逐步引导：授权辅助功能 → 确认语言包 →
  用一句示例文字试一次双击 ⌥，这样我确定装成功了、也学会了怎么用。
- 作为**任意用户**，我想点一下浮窗就把译文复制走，这样查完词能直接粘贴进笔记。
- 作为**设计师/游戏玩家**（⌥ 高频使用者），我想临时暂停双击监听，避免误弹浮窗。
- 作为**开发者用户**，我想从菜单栏一键"检查更新"，拉最新代码并重载，
  不用记 git 命令和 reload 流程。
- 作为**非技术用户**，出错时我想从菜单栏直接"打开日志"发给会电脑的朋友。

## 需求

### P0-1 服务状态显示与一键修复

- 菜单首项显示实时状态：🟢 服务运行中（含引擎可用性摘要）/ 🔴 服务未启动。
- 状态数据源：`/health` 探测。**打开菜单时即时刷新**（`hs.menubar:setMenu` 支持传
  函数按需构建），另以低频定时器（60s）刷新标题图标。
- 🔴 时菜单提供"启动/修复服务"：执行 `launchctl kickstart -k gui/<uid>/<label>`，
  失败则回退执行 `scripts/launchd_install.sh`，结果以 `hs.notify` 通知。
- 本项同时**修复既有初始化竞态**：`currentEngine` 初值由硬编码 `"volc"` 改为
  `"apple"`（对齐服务端默认）；`initEngineState` 的一次性 /health 探测改为
  失败后按 2s/5s/15s 退避重试；可用性标志随每次菜单打开的刷新更新。

验收标准：
- Given 服务未启动，When 打开菜单点"修复服务"，Then 10s 内菜单状态变 🟢 且翻译可用。
- Given Hammerspoon 先于服务启动（模拟开机竞态），Then 无需 reload，菜单在服务
  就绪后 ≤15s 内自行显示正确引擎与可用性。
- Given 无持久化状态的全新用户且服务健康，Then 菜单默认勾选与服务端
  `default_engine` 一致。

### P0-2 云端 Key 配置对话框

- 菜单项"配置云端翻译…"：两步 `hs.dialog.textPrompt`（SK 一步启用 secure field），
  预填现有 AK（若有）。
- 提交后：写 `~/.config/argos-translator/volc.env`（保留文件中其他行如 ENGINE；
  chmod 600），kickstart 服务，探测 `/health` 确认 `engines.volc == true` 后
  提示成功并询问"是否切换到云端引擎"。
- 校验失败（写入后 volc 仍不可用）：提示检查 Key 与控制台开通状态，**不回滚文件**
  （用户可能只是网络抖动），并给出"打开火山控制台"链接项。
- 对话框文案不回显完整 SK；日志（appendLog）只记事件不记键值。

验收标准：
- Given 从未配置过云端的用户，When 走完对话框输入有效 Key，
  Then 无任何终端操作，菜单中"云端"变为可选且切换后翻译成功、来源标注"火山云端"。
- Given 输入无效 Key，Then 得到明确失败提示与下一步指引，apple 引擎不受影响。
- volc.env 权限为 600；HS 日志中 grep 不到 SK 明文。

### P0-3 首次运行向导

触发条件：无 `hs-engine` 状态文件且无向导完成标记文件（`~/.config/argos-translator/onboarded`）。
步骤（每步可跳过，完成或跳过全部后写标记）：

1. **授权检查**：`hs.accessibilityState(true)` 主动弹系统授权；未授权时阻塞性
   提示"不授权则热键完全不可用"。
2. **服务检查**：复用 P0-1 探测与修复。
3. **语言包检查**：`bin/apple-translation-helper --status` 为 `supported`（未安装）时,
   引导执行 `--prepare` 并说明会出现系统下载确认框；`unsupported`/helper 缺失时
   说明将只能使用云端并指向 P0-2。
4. **上手试用**：弹出含一句示例英文的对话框，指导"选中下面这句 → 双击 ⌥"，
   检测到本次会话内首个 `translate_done` 成功事件后展示"完成 🎉 + 用法速记"。

验收标准：
- Given 全新安装（干净用户目录），When Hammerspoon 首次加载模块，
  Then 向导自动出现且按序走完后完成标记存在、双击 ⌥ 出译文。
- Given 用户在第 1 步拒绝授权，Then 向导可退出，下次 reload 重新提示且不重复
  已完成步骤。
- Given 老用户（已有 hs-engine 文件），Then 升级后**不会**看到向导；
  菜单提供"重新运行引导"入口兜底。

### P0-4 浮窗复制译文

- 点击浮窗本体（现"点外部消失"逻辑取反区）：将**译文正文**写入剪贴板，
  浮窗短暂显示"已复制"后消失。
- 错误态浮窗（Spec 3 P0-1）点击复制错误详情（便于粘给别人求助）。
- "翻译中…"过渡态点击不复制、仅消失。

验收标准：Given 译文浮窗显示中，When 点击浮窗，Then 剪贴板内容恰为译文
（不含"来自 …"副标题），且原剪贴板的这次覆盖是用户主动行为（不做快照恢复）。

### P1-1 暂停/恢复监听

菜单开关"暂停翻译"：stop/start eventtap，标题图标加暗示（如 ⏸），状态持久化到
hs-engine 同目录文件，重载后保持。

### P1-2 检查更新

菜单项"检查更新"：`git -C $ROOT fetch` 比对本地与 origin/main，落后则提示
变更摘要并一键 `git pull --ff-only` + `hs.reload()`；工作区脏或非 ff 时提示
改用手动流程。仅在 `.git` 存在时显示本项（tarball 安装时隐藏，与 Spec 2 联动）。

### P1-3 菜单杂项

- "打开日志"：`open ~/Library/Logs/`（选中两份日志文件所在目录）。
- "运行诊断"：后台跑 test.sh，完成后 `hs.notify` 摘要 + 打开输出文件。
- "关于/用法"：一条 disabled 项常驻显示"双击 ⌥ 翻译选中文本"。

### P2（记录在案，不实现）

- 浮窗字号/宽度/双击窗口时长的菜单化调节（写入本地配置文件，Lua 读取）。
- Web 设置页（FastAPI 已在 54321，加 /settings 静态页 + 菜单跳转）。
- 状态栏图标随错误闪烁/角标等更强的状态可视化。

## 成功指标

- 领先指标（本机 JSONL 日志新增 `wizard_step`/`menu_action` 事件）：
  向导完成率（走到第 4 步成功翻译的比例）≥80%；"修复服务"点击后 10s 内
  /health 转绿的成功率 ≥95%；`trigger_failed(no_selection 之外)` 与
  "connect_failed" 类事件占比相比基线下降 ≥50%。
- 滞后指标：GitHub"装了没反应/怎么配云端"类 issue 归零；
  README 安装章节可删去"手写 volc.env"作为主路径（降级为附录）。
