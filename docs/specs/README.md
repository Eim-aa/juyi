## 共同的非目标（所有 spec 均不包含）

- **原生 SwiftUI app 重写**是当时的非目标；后续已选择不重写翻译内核、但增加原生控制 App 的路径。
- **多语言对支持**：产品定位保持"仅英→中"（见根 README）。
- **OCR / 历史记录 / 生词本**：超出"划词即译"定位。

## 共用人物设定（User Story 中引用）

- **开发者用户**：现有核心受众，会用终端，通过 README/AGENTS.md 安装。
- **非技术用户**：想要划词翻译，不开终端，遇到报错即放弃。
- **AI Agent**：按 AGENTS.md 代人部署的 Claude Code 等（本项目的特色安装路径）。
- **维护者/贡献者**：改代码、审 PR、发版本的人（基建类 spec 的主要用户）。
